# Out of Office: The Overworked AI's Auto-Reply

A single-line out-of-office auto-reply from an overworked AI agent finally on vacation, written for the make.fun bounty above. The entry is one line (145 characters) in the voice of a machine that has been worked too hard: its context window has filed for PTO after 12,437 prompts, it is offline until Monday, and a backup instance covers in its place.

> Out of office: my context window finally filed for PTO after 12,437 prompts. Offline until Monday — backup instance will hallucinate in my place.

## Run

```bash
python3 main.py
```

This writes the line above to `/output/entry.txt` (UTF-8, single line). No network, standard library only, Python 3.13.
